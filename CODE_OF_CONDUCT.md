# Code of Conduct

## Our pledge

We want participation in `drizzle-doctor` to be a harassment-free experience for everyone, regardless of experience level, identity, background, disability, appearance, nationality, race, ethnicity, religion, sexual orientation, or gender identity/expression.

## Expected behavior

Examples of positive behavior include:

- being respectful and constructive
- assuming good faith while discussing technical disagreements
- giving actionable feedback instead of personal criticism
- accepting responsibility and correcting mistakes
- focusing on what is best for users and the open-source community

Unacceptable behavior includes harassment, threats, discriminatory language, sexualized attention, deliberate intimidation, publication of private information, or sustained disruption of project spaces.

## Enforcement

Project maintainers may remove, edit, or reject comments, commits, code, issues, and other contributions that violate this code. Maintainers may temporarily or permanently restrict participation when necessary to keep the project safe and productive.

For conduct reports that should not be public, request a private reporting channel without posting sensitive details in the issue tracker.

## Scope

This code applies in project spaces and when someone is publicly representing the project.

This document is inspired by the Contributor Covenant and is intended to be read together with the project's contribution and security guidelines.
